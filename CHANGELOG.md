# Changelog

Every release of RagX, one section per tag, one block per part.

## v1.2.3 — 2026-10-21

### api

- A cancelled RabbitMQ `get` lets its in-flight `basic.get` finish under a shield and returns a message that arrived late to the queue before the cancellation propagates. Cancelling the RPC used to make aiormq close the broker's shared channel, so stopping workers mid-pull broke the next operation on the same broker (the v1.2.2 release gate failed on a purge after `jobs.stop()`) and stranded the fetched message until the channel closed. A test cancels a pull at six points around the RPC on every broker and proves the broker stays usable and the message stays queued.

## v1.2.2 — 2026-10-21

### api

- The RabbitMQ recovery test now waits until the redelivered job is acknowledged before cutting the broker, and after the outage asserts what AMQP guarantees: no job is lost, the new job runs once, and the redelivered job may run once more, since an acknowledgement in flight when the connection drops is lost and the broker delivers the job again. It used to expect exactly once and failed about one run in ten (the v1.2.1 release gate); a traced failure showed `[1, 2, 2, 2, 3]`.

## v1.2.1 — 2026-10-21

### infra

- Infra 0.2.1. The API image upgrades its Debian packages at build time, as the web image already does with Alpine, so an OS security fix ships before the pinned base image is rebuilt upstream: the v1.2.0 deploy was stopped by Trivy on `ca-certificates` (DSA-6572-1, the emSign roots), which the newest `python:3.15-slim` still carried.

## v1.2.0 — 2026-10-21

### infra

- Infra 0.2.0. Commands with actions declare them once in `COMMAND_ACTIONS`, the default first: the dispatch, the overview usage (`backup [create|list|verify] [BACKUP]`) and a new Actions section in every manual read that table, flags print in one aligned column, headings and command columns are colored on a terminal (`NO_COLOR` turns it off), and a mistyped action names the closest one and the alternatives.
- A routed command forwards its `-e` overrides over SSH stdin, never `SSH_*` or `REMOTE_*` and never in argv, so `infra -e API_REPLICAS=4 scale` acts on the server (the overrides used to be dropped silently), and an unknown action is refused before any SSH connection.
- Retries where repeating is safe: image pulls and registry logins, image pushes (20 s and 40 s, GHCR's grant delay, moved from the Deploy workflow into `infra registry push`), `server stage` uploads, a `server run` start that never reached the server (the server claims each job id atomically before launching, so a cut-off start is reported and never run twice), curl `--retry` on HTTPS reads, and aws-cli's standard mode with five attempts for offsite backups.
- The release bundle embeds every asset byte for byte (each asset used to gain a trailing newline), and `Bash.toml` is read by a stricter TOML subset: trailing comments after values and tables, dotted tables declared once, no leading zeros, no escapes TOML lacks; settings keep their file order, so `infra config` prints them as the schema lists them.
- Validation now covers `TLS_EMAIL`, `HEALTH_CA` and `PORTAINER_CA` (a comma could add mount options), `GITOPS_BRANCH`, `BACKUP_REGION`, `REGISTRY_NAMESPACE`, `SSH_HOST`, `SSH_USER` and `REMOTE_DIR`.
- `doctor` warns when rootless Docker publishes the edge, since its port forwarding shows every client as the network gateway to logs, per-IP limits and trusted proxies; the relay mode keeps client addresses.
- `.env.example`, `.env.production` and `.env.local` hold the same 127 keys in the same order under the same short comments, each followed by a blank line; the Alertmanager service fragment is `alertmanager-service.yaml.tpl`, distinct from its configuration template.

### global

- Deploy pushes each image once through `infra registry push`, which owns the retry.

## v1.1.0 — 2026-10-21

### api

- One model spec for every provider: `core.llm.Model` (`model url key name driver tasks serves headers timeout retries window options`) builds `chatgpt claude gemini deepseek local` alike; the core knows no model name and no local/remote split, and remote defaults are gone. Models declare tasks (`generate summarize evaluate embed rank ocr describe transcribe`), boot refuses a model that cannot serve its task, and `llm.task(name)` routes; `Llm.setup(models, …, tasks)` replaces the named shortcuts (`llm.local()`, `llm.chatgpt()` …).
- One tuning vocabulary (`temperature top_p top_k stop seed presence frequency effort extra`) mapped onto each wire; a knob a provider lacks is dropped and logged, a feature it lacks stays a `Fault`. Effort reaches OpenAI-compatible servers as `reasoning_effort`, Claude as `output_config.effort`, Gemini as `thinkingConfig.thinkingLevel`. Compaction runs on the `summarize` model when one is registered.
- `transcribe(media, language)` over OpenAI-compatible `/audio/transcriptions` with timed segments.
- `config/llm.py`: one `Endpoint` per model (`writer summarizer embedder ranker vision listener chatgpt claude gemini deepseek`) filled from `LLM_<MODEL>__*` keys without losing its declared tasks; keys stay out of the runbook. The old `LLM_DRIVER`, `LLM_LOCAL_*`, `LLM_EMBEDDER_*`, `LLM_RANKER_*` and `LLM_<PROVIDER>_*` keys are gone.
- Extraction reads documents, sheets, mail, images, audio and video in a sandboxed worker: pdfium with a pypdf fallback for reversed or garbled Arabic pages, Kreuzberg for Office, OpenDocument, RTF, EPUB, HTML and mail, python-calamine for sheets, charset-normalizer for legacy encodings, Pillow and PyAV for media metadata and embedded subtitles. What code cannot read comes back as typed gaps (`ocr vision speech frames`), with `render still clip frames` to feed them to models; the `Converter` hook is gone.
- `core.rag` is a facade (`rag`) over flat stages: `Reader` fills gaps with the `ocr`, `describe` and `transcribe` models, `Retriever` fuses query rewrites by reciprocal rank, `Writer` answers on an optional session and summarizes long sources in rounds, `Judge` evaluates; every verb takes `provider=` and tuning.
- `core.test.sample` builds real PDFs, scanned pages, Word, Excel, zip, WAV and PNG files from the stdlib for tests and benches; `bench_extract` measures the sandboxed extraction.
- The egress client tries up to four checked addresses of a name in order, so a dual-stack host whose first address refuses still connects while a crowded answer cannot multiply connection attempts.
- Database sessions run in UTC whatever the server's time zone, so `where_date` and every date cast agree with the core clock (a session in `Africa/Cairo` counted a day off between midnight and 03:00).
- kreuzberg 4.10.4, pypdfium2 5.14.0, python-calamine 0.9.0, pillow 13.0.0, charset-normalizer 3.5.2 and av 19.0.1.

A test proves the manual and the dispatch agree.

Webhook bodies are signed with HMAC-SHA256 computed in Bash, so the secret never enters argv, and verified against OpenSSL and Python. Alertmanager routes alerts to Telegram and Slack. `ALERT_BOT_TOKEN` and `ALERT_CHAT_ID` became `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`. Edge rollbacks, renewal failures, start, stop, uninstall and scale now notify too.

- `infra.yml` smoke-tests the release bundle (checksums, version, help, a refused flag) and summarizes the tests and the bundle checksum; `deploy.yml` lists the pinned images in the job summary and posts the run link to every channel when it fails.

## v1.0.0 — 2026-10-19

### api

- First real release: an enterprise `core/` of 42 domains proven on real PostgreSQL 18 + pgvector, Redis 8, RabbitMQ 4 and llama.cpp models, under an empty, law-checked Laravel-shaped application that serves `/health`, the docs and the assets. The business that exercised the core (tenants, roles, panel and tenant-key auth, user sync, AI, human and hybrid conversations over SSE and WebSocket, per-tenant retrieval) was built, proven end to end, and removed; its lessons stay in the core.
- Recovery on real systems: a Postgres connection idle past 5 s is pinged at checkout and replaced (a blanket pre-ping cost +5–8 ms p50 and was refused); a Redis outage is a fault for reads and locks while throttles degrade to a local counter; RabbitMQ publishing fails explicitly while down, consumers resume, an ack on a dead channel is a fault and the message is redelivered; queue workers survive any `Fault` with a bounded backoff instead of dying. `core.test.Relay` cuts and restores a real service mid-operation.
- Tenancy in the schema DSL: `blueprint.isolated()` forces a fail-closed row-level security policy that still uses the index, `database.bound(...)` and `database.follow(setting, slot)` bind the tenant per transaction from the request context into the jobs and events it raises, and `42501` is `FORBIDDEN database.privilege`. `python -m bootstrap provision` creates the runtime role without `SUPERUSER` or `BYPASSRLS`, its own database and the extensions; CI runs `pgvector/pgvector:0.8.7-pg18` with that role, so the pgvector and RLS suites no longer skip.
- Egress, safety and quality: user-supplied URLs go through an SSRF-safe egress (public addresses, pinned connections, redirects checked per hop); archives refuse bombs by member count, total size and ratio; redaction masks Luhn-valid card numbers; a quality-gate DSL (cases, checks, recall, judge floor) turns a failed evaluation into `rag.quality`.
- Models: exact token counting through the model server's own tokenizer refuses a prompt that cannot fit before it is sent; `Builder.ground` sends retrieved sources for one turn without storing them in a durable session; `Rag.stream` streams a grounded answer and ends with its `[S#]` citations.
- Fixed: an SSE keep-alive ping cancelled a slow source, killing any model that took longer than the ping to start (one producer task now drains every stream, and a fault becomes an `error` event); importing `bootstrap` loaded `.env` before the test environment, so the suite ran on the development database (the application is now a factory and the shared fixture refuses a non-test database); the in-process test client leaked context between requests; a duplicated test file name silently hid a suite (now a law); `Mapping` model fields bind as JSON; `restrict_violation` is a typed fault.
- `python -m bootstrap check` boots twice and fails when any core registry or task leaks between boots; health checks moved from the application into the framework.
- Tests and benches that relied on the product became small apps: `test_application`, `test_orm`, `test_journey` (outbox → RabbitMQ worker → RLS pgvector index → Redis broadcast → SSE citations), `bench_hello`, `bench_auth`; `bench_models` measures a live model stack. Verified live on llama.cpp (CPU, 2 threads each): Qwen3.5-2B, Qwen3-Embedding-0.6B and bge-reranker-v2-m3 answer English and Arabic questions with the right citation; the verified weights live in `~/.cache/ragx/models` by sha256.
- Gate: ruff 0, mypy 0, pytest 185 passed with 14 opt-in skips, `bootstrap check` passed, every bench within budget.

- Earlier work in this release:
  - The whole part moves under `src/` (`core app config routes bootstrap database views storage`), with `tests/` and `benches/` beside it.
  - `core/database` rebuilt on SQLAlchemy Core (asyncpg driver) behind an `Adapter` (PostgreSQL today): a migration DSL with no SQL in migration files (`id uuid string text integer boolean json decimal enum foreign morphs timestamps soft_deletes index unique`, alter/rename/drop), a batch migrator with rollback, and a generative `Query[M]` ORM over frozen dataclass models with `belongs_to has_one has_many belongs_to_many morph_many morph_to`, soft-delete scopes, pagination and typed faults; uuid7 primary keys by default.
  - New domains: `crypto` (argon2id, Fernet with rotation, digests, HMAC), `token` (JWT adapter, claims, bearer parsing), `mail` (SMTP/log/memory transports, a mailable DSL), `view` (Jinja, async), `validate` (pydantic adapters cached per type), `value`, `rand`, `func`, `cache` (with a sliding rate counter), `net`, `fs`.
  - Route DSL: `Route.get/post/…`, `.guarded(*deps)`, `.limited("60/minute")`, `.constrained(key="int")`, `Route.group(prefix, routes, tags, middleware, throttle, name)`, `Route.resource(prefix, controller)`; throttle answers `429` with `X-RateLimit-*` headers.
  - Auth lifecycle: `POST /v1/auth/register|login|refresh|logout`, `GET /v1/auth/me`; argon2id passwords hashed off the event loop, stateless access tokens, hashed and rotated refresh tokens in a `tokens` table (morph owner), roles through `role_user`, a welcome mail rendered from `views/mail/`.
  - Reads and single-statement writes run on autocommit connections from one warm pool; string filters bind untyped so PostgreSQL infers enum, uuid and text columns.
  - Tests: brutal flat files (laws, core, database, http, auth, storage, pipeline, realtime) against the real `ragx_test` database; flat benches (hello, auth, micro, socket) that fail on any non-200 or a blown p99 budget.
  - `core/config`: `env` loads `.env` then `.env.<mode>` (`local`, `testing`, `production`/`prod`) then `.secret` layers with the process environment on top; `config.register/get/set/remove` over typed settings per domain (`app auth broadcast database docs log mail queue schedule socket storage`).
  - `core/json` (orjson behind one facade) used by fs, value, net, http and the socket frames; unified types from core (`DateTime TimeDelta Uuid Path Decimal JsonValue`) with a law that no layer above core imports the standard library for them.

## v0.1.0 — 2026-10-17

### api

- A generic `core/` engine: `http` (routes, envelope, trace, handler, warm, lifespan), `database` (asyncpg pool, safe query builder, migrator, seeders, row mapping, error translation), `log` (structlog with spans), `error` (one typed fault and one code set), `config`, `context`, `thread`, `date`, `string`, `array`, `number`.
- One lifecycle through every layer: `GET /v1/hello` → controller → service → repository → `User` model → `users` table, with enums, dna (identity, timestamps, soft deletes) and the base classes.
- A parallel bootstrap that opens the pool, applies migrations, warms the OpenAPI schema and the hot routes, and reports its timings; `python -m bootstrap serve | migrate | seed | check`.
- `/health` reports the database pool and degrades to `503 unavailable` when it is gone.

### infra

- OpenTofu → Kubernetes → Argo CD → Helm stacks (`standard`, `light`, `full`) with the api wired to the same `DB_*` variables the api reads.

### web

- One Next.js engine for every surface: each spec chooses `output` (`export` or `standalone`), `seo` and `render`.
- SEO when a spec asks for it: metadata, canonical and language links, Open Graph and Twitter cards, `robots.txt`, `sitemap.xml`, `manifest.webmanifest` and JSON-LD, all derived from the spec and refused at compile time when they contradict it.
- Three specs saying hello: `super` and `admin` as client-only static exports, `client` as a server-rendered indexable site; one element, one component and one feature carry the greeting.
- A release server for exports with security headers, a Content Security Policy, brotli/gzip and weak validators, and a launcher for standalone builds.
