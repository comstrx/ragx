# Agents

This repository is governed by `skill/`. Read `skill/index.md` first and follow its reading order before you touch a file.
The files under `skill/` are the operating contract for every AI agent and every engineer who works here: the vision, the stack, the style, the way of working, and one file per part. They outrank default habits, tool conventions and prior assumptions. The code is the truth about the current state; `skill/` is the truth about how the code must be written, verified and shipped. Nothing outside the two is a source of truth.
